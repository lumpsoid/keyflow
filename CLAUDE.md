# Typing Practice

Flutter typing trainer. Mobile (Android, iOS) is the first platform, desktop
(Linux now; macOS/Windows later) second. Pure Dart, no native core.

## Layout

- `lib/typing/` the engine. `TypingSession` holds one round: input in,
  stats out. Time is always a parameter; no clock or widget code.
- `lib/history/` `History` (pure: personal bests, streak, averages) and
  `HistoryStore` (shared_preferences).
- `lib/texts/` `TextLibrary`: loads the bundled texts and picks a round's.
- `lib/practice/` `PracticeController`: the one owner of round order
  (pick text, feed input, tick, finish, record).
- `lib/models/` one model per file. `lib/pages/`, `lib/widgets/` UI only.
- `assets/texts/` generated by `tool/import_monkeytype.py`; never hand-edit.

## Rules

- Typing rules (what counts as correct, wpm, accuracy, finishing) live in
  `TypingSession` and nowhere else. Widgets render the session; they don't
  re-derive it.
- Input arrives through one hidden `TextField` whose text mirrors
  `session.typed`: the session drops malformed input and the page copies
  `typed` back. Keep `keyboardType: visiblePassword`; it stops Android
  keyboards composing and autocorrecting.
- The texts are Monkeytype's, under their own license. Keep
  `assets/texts/LICENSE` and the attribution in the settings sheet.
- The typing text uses the bundled JetBrains Mono (`assets/fonts/`, OFL)
  with ligatures off (`calt` disabled); its license is registered in
  `main.dart` so it shows on the licenses page.
- Follow `~/projects/agent-kit/conventions/CODE-PRINCIPLES.md`.

## Gates

On this machine, run the heavy Flutter commands through `agent-gated`:

    dart format lib test
    agent-gated flutter analyze
    agent-gated flutter test

Android and iOS stay disabled in this machine's global `flutter config`:
all builds run on CI. Don't enable them here.
